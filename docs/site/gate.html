You have a folder that is not one kind of file — some text, some already-compressed blobs, some binaries. Gate looks at each file and picks a lossless compressor: text goes to brotli at quality 11, everything else to gzip at level 9. You get the original bytes back.

What you do with it

Point Gate at a mixed pile. It does not invent a new compressor. It chooses among tools that already exist and that restore exactly. Use it when you do not want to sit there deciding “is this text?” for every file.

On public corpora this is not smaller than running brotli on everything. We publish that. If you need the zeros/ramp trick (10,000 zeros → 8 bytes), that is TRU8, not Gate.

It is

A mixed-file lossless picker. Text → brotli-11. Else gzip-9. 24-hour try, then a Gate seat.

It is not

A claim that we beat brotli as a general compressor. It is not Chamber (secrets) and not the game.
