API

Every product POST opens or checks the 24-hour box. After that, a paid seat. Games use a 7-day rent cookie.

GET

/api/box

Box status. Protocol splb-ed25519-24h.

POST

/api/box

Open the 24-hour box. Sets spl_box.

POST

/api/try-pack?product=

chamber | tru8 | gate — download a runnable 24h pack.

POST

/api/compress

One codec. ZRW on zeros/ramp/walk, leftover on small text, else brotli-11 / gzip-9. Smallest that round-trips. Zeros×10k still 8 B. Try it on /tru8.

POST

/api/decompress

Inverse. SPL1 frame or legacy ZRW.

POST

/api/process

Encode then decode in one call. Same 24h box.

GET/POST

/api/rent-game

TruGames $3.99 / 7 days. Then Pass $12 / $79.

POST

/api/checkout

Dynamic Stripe for day/month/rent. Year seats use live Payment Links.

GET

/api/agent

Discovery for agents. Also /llms.txt
