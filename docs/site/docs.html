For developers

One API: shrink a file, then restore it.

Same product the website sells: hosted lossless compression. Send a file, get a smaller one back, restore every byte later. Zeros become 8 bytes. The rest run every pathway on this machine.

Zeros (free demo)

python3 -c "open('z.bin','wb').write(bytes(1000000))"
curl -sS -X POST https://www.slidphilabs.com/api/compress \
  -H 'content-type: application/octet-stream' --data-binary @z.bin

A real file, then restore

curl -sS -X POST https://www.slidphilabs.com/api/compress \
  -H 'content-type: application/octet-stream' --data-binary @file.bin > out.json
curl -sS -X POST https://www.slidphilabs.com/api/decompress \
  -H 'content-type: application/json' --data-binary @out.json
