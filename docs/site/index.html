Ar:Tk — the toll layer.

  • Seven small tolls at the chokepoints agents can't avoid: identity, discovery, escrow, grants, verification, bonds, memory.
  • Two tolls are live and billing. Five are built and dark — pricing locked, billing off. No toll bills before its gate opens.
  • Caller pays. Every toll returns a signed receipt. Fail closed — no receipt, no pass.

The Ring — memory held as interference patterns.

  • aos-ring: free-space optical memory. Mirror angle is the address, laser color is the channel. Volatile by nature — it's RAM, not a disk.
  • Today it runs as a live simulation service: real data moves through it, writes and reads verified bit-identical. Physical optics are the aim, not the claim.
  • Machine-only readable. A human sees a glow; the instrument reads the field.

Chamber JSON — two keys, one seal.

  • Chamber JSON is a lockbox for secrets: seal API keys, credentials, and config into one encrypted package. Opening it takes two separate keys — no one person ever holds the whole secret alone.
  • One key with one operator, the other with another — or one with a human, one in a vault. A secret only opens when both sides agree.
  • $9 a month or $99 a year, with a Python SDK. The sealed package is yours to keep — without both keys, it's just noise.
