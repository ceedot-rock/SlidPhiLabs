Door 1 · lead product

PCC

Lossless compression as a service. Upload or one HTTP call. Every pathway on this machine; we keep the smallest result that still restores. If nothing shrinks it, we store it as-is so it never comes back larger.

Door 2 · local engine

TNSSRC

TriNeural Shared Spine Row Compression. Local npcc + closed grant. Silesia 43,724,575 bytes, verified 12/12 decode+SHA-256. AGPL $0 · grant $390/yr.

Door 3 · same plan

TRUSTREAM

Live logs, traces, telemetry. Empty stretches shrink. Noisy stretches stay the same size. Included with PCC.

Door 4 · free demo

pulsar

Free GPLv3 binary you run on your own machine. Not PCC. Not TNSSRC. Proof that invert exists without a seat.
