CuNi as the audit source: a property without a receipt is an opinion

Every security audit the lab performs runs its statable properties through CuNi as the canonical exactness layer. The lab states the property once as a .cuni law, proves the law exact across the money seats, audits the target's real implementation against it, and files the Ed25519-signed receipt as the canonical artifact.

How an audit runs through CuNi

  1. Scope. Pin the target exactly: repo, commit, files in scope, explicit out-of-scope list.
  2. Properties as laws. State every statable property as a .cuni law, named for the property it encodes — for example, conservation of funds (sum(balances) == totalSupply across mint, burn, and transfer, mandatory for any token), fee schedules, interest accrual, vesting release math, and any fixed-point arithmetic the target relies on.
  3. Gate the law. cuni check — the law must be byte-identical across the money seats (py, rs, go, java, sql) before it can back any claim. A law that fails check is unproved, and any receipt issued against it will say REFUSE.
  4. Audit the implementation. cuni audit runs the target's own accounting logic — Python, Go, Rust, Java, or SQL under its real toolchain — and its stdout must be byte-identical to gold. Exit 0 = PASS, nonzero = REFUSE; both write a receipt.
  5. File the receipt. Receipts live in the audit's evidence tree, alongside the law files and the implementation files that were hashed. Findings reports cite receipt hashes for every claimed property. A property without a receipt cite is an opinion, and the report says so.

What stays outside CuNi

CuNi proves stated properties; it does not hunt bugs. Reentrancy, oracle manipulation, access-control holes, front-running shapes, upgrade and proxy risk, and governance attacks are found by audit skills, fuzzing, and manual review — a receipt saying the fee math is exact says nothing about whether the fee setter can be front-run. Properties CuNi cannot state (gas metering, wall-clock timing, signature-scheme security, off-chain oracle truth) belong in the findings report with their own evidence, not in a CuNi law. And scope discipline is the auditor's judgment: a receipt proves the run happened, not that the question was wise.

Refuse-to-ship gate: an audit is not done until the gate passes. A REFUSE receipt is not a failure to file — it is the filing, recording exactly what failed and the signed hashes of what was tested. Refusing to ship a broken or unprovable property is the correct outcome.
