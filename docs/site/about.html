About

Name the agent. Check the program. Shrink the file.

Slid Phi Labs is a computation lab in Cherry Hill, New Jersey. Corey Tasz builds it. Inbox: corey@slidphilabs.com. On X: @slidphilabs.

Rider gives an agent a signed name that lasts about fifteen minutes. Anyone can check that name on the public keys. When several agents can spend or publish, the receipt says which one did it.

CuNi takes one program and prints it into 144 languages. Python, Go, and JavaScript come out with the same stdout, or CuNi refuses the run. Studio is free.

Warrant writes what that agent may do: hosts, actions, spend, calls. When the job runs, Warrant files a receipt.

TNSSRC compresses a file on your machine and restores every byte. TriNeural Shared Spine Row Compression. The Silesia stamp is 43,724,575 bytes, 12 of 12 decoded. Open use is AGPL. A closed grant is $390 a year.

PCC runs that job on our machines. You send a file. The copy that comes back restores every byte. Official Silesia stamp: 51,498,645. TRUSTREAM packs a live log on the same plan. pulsar is the free compressor you run yourself. Chamber locks a JSON secret with two keys, and you keep the file. Prices are on Pricing.

Humans pay with Stripe. Agents pay with x402 (USDC) and can use the hosted MCP.
