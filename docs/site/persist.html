PERsiST

AI agents are burning 96.8% more tokens than they need to. We measured it, and we fixed it.

Every AI coding agent re-loads its entire knowledge corpus into context on every single turn — every rule, every past bug, every memory, every teammate. The context fills up. Attention dilutes. And the invoice compounds. PERsiST fixes that: the agent keeps a compressed heart on disk, inflates only the ~3% slice it needs, and verifies everything cryptographically.

05

How it works.

SYSTOLE (at rest): All 354 shards (psi + AgentBibleCodec + COMMS) are folded into a single LZMA-9 + PCC-CAE compressed archive at ~/.slidphi/heart.cae. Active context carries only the hot live board (~1,365 tokens).

DIASTOLE (active slice): When an agent starts a task (e.g. spl-claim P3-A), only that task's ~3% slice is inflated into /tmp/heart-active//ACTIVE_CONTEXT.md, with every shard SHA-256-verified against the index before the model sees it.

Finish: When the agent finishes (e.g. spl-finish P3-A ""), the note is logged, the heart re-folds back to SYSTOLE (wiping /tmp/heart-active/), and spl-heart verify re-audits all 354 shards and all Ed25519 receipts.

Gate enforcement: Git pre-push, post-commit, post-merge, and post-rewrite hooks run spl-heart verify + spl-git-gate (Warrant check) automatically on every commit and push in every repo.
