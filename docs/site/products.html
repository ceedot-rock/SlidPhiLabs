Tools that earn their keep

A Cherry Hill lab. Five products. The compressor is priced to beat the usual cloud bill. The other four stop a secret, an agent, or a program from lying. Nothing here is a toy name for the same SKU.

Files · $9 / day · $49 / mo · $490 / yr

AWARE

Send a file. Get a smaller file back. Restore every byte when you need it. First 2 GB each month are free. $49/month includes 200 GB — Cloudinary’s first paid plan is $99. After that, 8¢/GB, which undercuts AWS S3 charging ~9¢ just to ship the file out uncompressed. You run it on our machines. You do not get a copy of the encoder.

Streams · included with AWARE

TRUSTREAM

The same plan, for live logs. Agent traces, SIEM, telemetry in 4 KiB tiles. Long runs of zeros collapse. Already-random junk stays the same size — it never inflates. You are not buying a second compressor and you are not replacing zstd on general text. You are buying a pipe that does not punish empty or noisy chunks.

JSON secrets · $9 / mo · $99 / yr

Chamber

Something in JSON that should not sit in the clear. Chamber splits the key in two and seals the payload. One share is useless. You store the blob yourself — we do not hold it. Stop paying and old seals still open if you have both keys. You only pay to make new ones. 24-hour try, then a month or a year.

Agent identity · $79 / mo · $790 / yr

Agent-Rider

If more than one agent can spend, fetch, or publish, you need a name that is not “the bot.” Rider issues a signed credential (L0–L4) so you can prove which agent acted. Lab Pass does not include it. Rider Ops ($29 / $290) watches the fleet and alerts you when a signed agent goes quiet.

Language · playground $0

CuNi

Write one program. CuNi prints it into many languages. Python, Go, and JavaScript must print the same thing, or the compiler refuses. No “close enough.” Studio is free in the browser. Shipping CuNi inside a closed commercial product is $490/year per product.
