Who acted

Agent-Rider

When more than one agent can spend or publish, Rider issues a signed ID so you can prove which agent acted.

One program

CuNi

Write one program. CuNi emits a 53-entry catalog — the top 50 languages plus 3 onchain profiles, with emitters for ink!, Move, Vyper, Cairo, Clarity, and Cadence. Same stdout or refuse. cuni audit proves a foreign implementation matches byte-for-byte, filed as a signed Ed25519 receipt. Studio is free. Closed commercial embed is $390/year.

Permission and a receipt

Warrant

A signed mandate: these hosts, these actions, this spend cap. Then a receipt when the job runs. Pair X-Agent-Rider with X-Agent-Warrant.

On our machines

PCC

Hosted lossless compression. You send a file. We return a smaller one that can still become the original, byte for byte. Backups, datasets, archives, logs. You do not install anything. Source is dual-licensed. A PCC seat runs every own pathway on our machines.
