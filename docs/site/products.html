Door 1 · files

PCC

Hosted lossless compression. You send a file. We return a smaller one that can still become the original, byte for byte. Backups, datasets, archives, logs. You do not install anything. Source is dual-licensed. A PCC seat runs every own pathway on our machines.

Door 2 · local engine

TNSSRC

TriNeural Shared Spine Row Compression. Local npcc + closed grant. Silesia 43,724,575 bytes, verified 12/12 decode+SHA-256. AGPL $0 · grant $390/yr · bake-off $19.31/mo on a PCC seat.

Door 3 · streams · included with PCC

TRUSTREAM

The same plan, for live logs. Agent traces, SIEM, telemetry. Empty stretches shrink. Random junk stays the same size — it never inflates.
