Who acted

Agent-Rider — When more than one agent can spend or publish, Rider issues a signed ID so you can prove which agent acted.

Rider registers an agent and mints a short ES256 credential. Any peer checks that signature against the public keys, then checks the public revocation list.

One program

CuNi — Write one program. CuNi emits a 53-entry catalog — the top 50 languages plus 3 onchain profiles, with emitters for ink!, Move, Vyper, Cairo, Clarity, and Cadence. Same stdout or refuse. cuni audit proves a foreign implementation matches byte-for-byte, filed as a signed Ed25519 receipt. Studio is free. Closed commercial grant is $490/app/year.

CuNi 0.10.0 checks one source across 53 targets. Python, Go, and JavaScript must print the same stdout. A seat that would drift refuses.

Permission and a receipt

Warrant — A signed mandate: these hosts, these actions, this spend cap. Then a receipt when the job runs. Pair X-Agent-Rider with X-Agent-Warrant.

Warrant binds hosts, actions, spend, calls, and an expiry to a Rider. After the job, a receipt files what ran.

On our machines

PCC — Lossless compression through your tools. You send a file. We return a smaller one that can still become the original, byte for byte. Backups, datasets, archives, logs. You do not install anything. Source is dual-licensed. A PCC seat runs every own pathway on our machines.

PCC is lossless compression through your tools. Official Silesia 12 packs to 51,498,645 bytes. Decode returns the original.
