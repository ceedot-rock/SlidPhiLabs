Lossless means the file that comes back is the file you sent. If we cannot make it smaller, we keep it as-is so it never grows.

Hosted means we run it. Website, one HTTP call, npm, or MCP. You get the smaller file.

Dual-licensed. Every engine we bring forward is available two ways. Use the public source under the open license, or pay a seat and ship it inside a closed product. The hosted service is the same family: an AWARE seat is the grant that runs those pathways on our machines. pulsar’s closed-product grant is $490/year. CuNi’s is $490/year. Chamber, Rider, and Warrant seats cover theirs. Full list: licensing.json.

What people send. Backups. Datasets. Archives. Log history. Live logs use the same plan (TRUSTREAM). A folder becomes a .pcc file — our zip: many files, one container, this compressor inside.

How a job runs

1

You send the file

Website, POST /api/compress, npm, or MCP.

2

We shrink it

Zeros become 8 bytes. Everything else: every pathway we have, smallest restore-safe result.

3

You keep the small copy

Store it, ship it, archive it.

4

You restore later

POST /api/decompress. Every byte of the original comes back.
