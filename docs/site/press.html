Slid Phi Labs opens dual-licensed hosted lossless compression and publishes npm clients

CHERRY HILL, N.J. — September 9, 2026 — Slid Phi Labs today opened AWARE, hosted lossless compression, under a dual license, and published four npm packages that call the live host. You send a file. The lab returns a smaller copy that still restores every byte.

What it is. AWARE is lossless compression as a service. Upload on the website or one HTTP call. The machine runs every compression pathway the lab owns and keeps the smallest result that still becomes the original. All-zero files become 8 bytes. If nothing shrinks the file, it is stored as-is so it never comes back larger. Restore is the same host: send the packed copy, get the original back.

Dual license. Every product the lab brings forward is available two ways: open terms, or a paid commercial grant to ship inside a closed product. The hosted service is that family running on the lab’s machines. An AWARE seat is the grant for hosted use. pulsar’s closed-product grant is $490/year. CuNi’s is $490/year. Chamber, Rider, and Warrant seats cover theirs.

npm clients, not stubs. These packages call POST /api/compress and POST /api/decompress. They do not ship the encoder.

.pcc is our zip. A .pcc file holds many files in one container, each compressed on this machine. Pack with POST /api/archive or zip() on npm. Unpack with POST /api/unarchive. On your machine: lb zip out.pcc folder/.
