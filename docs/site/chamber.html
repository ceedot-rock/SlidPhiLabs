Security model

Built as a security product.

φ-split shares

Message key split into two keyword lists. Either list alone is useless; both required to reconstruct.

Tamper-evident license

HMAC-SHA256 signed license under ~/.chamber/. Any edit fails the signature and triggers permanent shutdown.

AES-256-GCM

Authenticated encryption with associated data chamber-v1. Public integrity tag binds shares + nonce.

Hard kill path

At 24h the chamber writes a KILLED marker and refuses every operational call until a purchased key is supplied.
