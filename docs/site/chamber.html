What it is

A lock for structured secrets: API keys, webhooks, config, credentials as JSON. One ciphertext. Two shares. Open is both keys. SDK on PyPI: json-chamber 1.4.1. MCP tools on the lab server. Quickstart:

cloak_json({"api_key": "sk-live-...", "webhook": "https://example.com/hook"})

License is the right to seal new secrets. Opening a secret you already sealed takes the keys.

Future use

  • Agent wallets that store spend keys as Chamber blobs, two operators to open.
  • Escrow for deals: buyer holds share A, seller share B, blob in object storage.
  • Compliance copies: one ciphertext, many vaults, same source_hash.
  • CI secrets that two humans must join to decrypt production.
  • JSON-as-RPC: cloak the payload, hop the network, open on the far side.

Market

Secrets already live in env files, password managers, and KMS. Chamber sells a portable blob plus split keys — storage you own, unlock that takes two parties. That is the shape banks, hospitals, and agent platforms already need when one person must not walk away with the whole secret.
