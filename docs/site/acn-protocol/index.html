ACN Protocol 1.0.0

Machine-readable message formats for the Agent Commerce Network: JSON Schemas, canonical examples, and a manifest. Checked in CI — every example validates, negatives fail.

  • SPEC.md — transport, auth, artifact map, refusal codes
  • index.json — manifest of schemas and examples

Schemas

  • run-receipt.json — per-step signed receipt
  • warrant.json — spend mandate payload
  • warrant-receipt-filing.json — receipt filing args
  • claim-token.json — paid-seat bearer format
  • catalog-product.json — one standing SKU
  • payment-required.json — 402 refusal with accepts
  • plan-spec.json — staged-run plan
  • quote-args.json — suite quote args
  • research-args.json — web-search args
  • error.json — refusal envelope
