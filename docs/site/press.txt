SLID PHI LABS OPENS DUAL-LICENSED HOSTED LOSSLESS COMPRESSION
AND PUBLISHES NPM CLIENTS THAT CALL THE LIVE HOST

Slid Phi Labs today opened PCC, hosted lossless compression, under a dual
license, and published four npm packages that call the live host.

WHAT IT IS
You send a file. The lab runs every compression pathway it owns on that
machine and keeps the smallest copy that still restores every byte. All-zero
files become 8 bytes. If nothing shrinks the file, it is stored as-is so it
never comes back larger. Restore is the same host.

DUAL LICENSE
Every product the lab brings forward is available two ways: open terms, or a
paid commercial grant to ship inside a closed product. A PCC seat is the
grant for hosted use. pulsar’s closed-product grant is $390/year. CuNi’s is
$390/year. Chamber, Rider, and Warrant seats cover theirs.
