What it is

A language of exactness. You write one .cuni source. Native seats today run native: py, go, js, ts, c, cpp, rs, rb, lua, and Solidity (sol). Other catalog ids emit and lower until that seat is native. If stdout would drift, CuNi refuses — no soft PASS, no approximate. Software already exists in more languages than teams can keep honest — CuNi sells the proof that they match.

Future use (not live yet): a tiny runtime that lands on any OS and emits the local seat; pricing and license rules printed into every language a company ships; CI that fails when Go and Python would disagree.
