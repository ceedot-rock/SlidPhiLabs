What it is

A language of exactness. You write the program once. You emit Python, Go, JavaScript, TypeScript, C, C++, Rust, and the rest of the catalog. Native seats run native. Other ids emit and run through a lowering until that seat is native. If stdout would drift, CuNi stops and does not publish.

Bank takes a deposit in Python (v1 subset) and emits another catalog id, then proves. cuni bank paste IN --from py --to js. Studio: /bank. API: POST https://cuni-studio.fly.dev/api/bank.

cuni run is the in-process check seat: same gold, no extra language. Protocol: cuni-protocol.json. Dual license: AGPL-3.0-or-later, or SKU cuni-exception $390/year for one closed product.

Future use

  • A .cuni plus a tiny runtime that lands on any OS, sees which compilers exist, emits that seat, and proves.
  • Pricing, meters, citizenship, and license rules printed into every language a company ships.
  • Agent tools that generate a program once and hand each host its proven copy.
  • CI that fails the build when Go and Python would disagree.
  • Spatial choosers (NCA / Autonoma) picking the seat from the machine around them.

Market

Software already exists in more languages than teams can keep honest. Drift is the tax: a Python script that lies in Go, a policy that only holds in one runtime. CuNi sells the proof that they match. Whoever owns that proof owns the contract between humans, agents, and the code they ship.
