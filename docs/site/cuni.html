CuNi

Tired of a script that works in Python and lies in Go? Write it once. CuNi prints that program into many coding languages. Python, Go, and JavaScript still have to print the same thing, or the compiler refuses. There is no “close enough.” Studio is free in the browser.

What you get: a browser playground where you write a program, emit it, and pick the language in a list. Hit exactness and Studio runs Python, Go, and JavaScript. If those three would not match, it says no and does not publish.

Who it is for: people who are tired of a script that works in one language and lies in another. Teams that need one rule, printed everywhere.

Studio is free. Dual license: AGPL-3.0-or-later, or SKU cuni-exception $490 / year to ship CuNi in a closed product.
