How these numbers were made — read this first

Every number on this page is an estimate. Nothing here is a measured saving. The free Archive Bytes Audit exists to replace these estimates with measured numbers, on each organization's own data.

Formula: Estimated annual saving = estimated holdings × 75% × $276 per TB per year

  • 75% saved comes from PCC's single measured result: on real agent-context material it compressed files to 25.4% of their original size (30/30 round-trips byte-exact). That was not measured on scientific data, so real results will differ by data type — some data compresses far better, some far worse.
  • $276 per TB per year is the assumed list rate for S3 Standard storage ($0.023/GB/month × 12). Real storage costs vary by provider, tier, region, and discounts.
  • Holdings: where the target list carries a verified figure (e.g. Internet Archive 45+ PB), that figure is used and the row is marked Verified holding. Everywhere else the holding is a conservative tier estimate from the organization's type and scale — tiers of 10, 50, 100, 500, 1,000 or 5,000 TB — and the row is marked Estimated holding with the tier basis shown. No holding was invented from a guess; tiers are deliberately conservative.
  • Estimated compressed size is holdings × 25.4% (the measured remainder from the same PCC test).

20 of the 100 rows rest on verified holdings; 80 rest on tier estimates. Treat the totals below as an order-of-magnitude illustration of the opportunity, not a forecast.
