API

POST /api/warrant/issue — header X-Agent-Rider, body { actions, allow_hosts, max_usd, max_calls, ttl_seconds }. Or { "demo": true }.

POST /api/warrant/verify — header X-Agent-Warrant, optional { host, action }.

POST /api/warrant/receipt — same header, body { action, host, usd, request_sha256, result_sha256 }.

GET /api/warrant — discovery. GET /api/warrant?id=wrt_… — public record.
