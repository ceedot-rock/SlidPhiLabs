The job ticket. Allow these hosts. These actions (spend, fetch, publish, compress, invoke). This many calls. This many dollars. Then it expires or you revoke it. Verify is free. Issuing and filing receipts: first 3 issues and 10 receipts per operator per day are free. Above that, a Warrant seat.
