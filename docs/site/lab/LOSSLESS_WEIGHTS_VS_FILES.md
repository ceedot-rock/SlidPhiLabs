## Why this page exists

Industry R&D (2026) is loud on **lossless model-weight / checkpoint compression** (memory + throughput) *and* still measures **file/corpus codecs** with mixed exactness stories.

Slid Phi Labs already ships a residual story for **files and structured ints**. This matrix positions the same residual-zero / exact-RT discipline for a second buyer: **inference ops** packing agent weights and checkpoints — without opening private engines or claiming universal #1.
