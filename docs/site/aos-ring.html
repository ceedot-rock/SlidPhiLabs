Bits stored as light.

Write data as sustained laser interference patterns. Read it back bit-identical. Query by similarity. Delete by killing the pattern.

Open the Ring Source on GitHub

What it is

An optical memory service. Mirror angle is the address, laser color is the channel — wavelengths don't interfere, so channels stay orthogonal. Volatile by nature: storage is a sustained pattern, not a thing. Deletion decoheres the pattern, leaving no forensic remnant.

Verified

  • Write → read: bit-identical.
  • Similarity query: a 20%-flipped query returns the correct address.
  • Delete: reads return zeros after the kill.

Honest state

This is an experiment, not a product. The Ring is the future home of the lab's agent operating system work — machine-readable memory at light speed. Expect rough edges.
