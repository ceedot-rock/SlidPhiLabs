www.slidphilabs.com is the only public door

Updated 2026-08-12: public product face is TRU8; Try Gate retired.

Published 2026-08-04 · Week of 2026-08-04

A product you can’t find — or that links to a dead host — is a product that never gets tried. This week was about making the public door singular, live, and honest.

IP Guard: Infrastructure and go-to-market process only. No engine internals.

The process problem we fixed

Earlier links sometimes pointed at temporary hosting names or GitHub fallbacks when a deploy flapped. That breaks the evaluation process:

  1. Human finds the lab
  2. Human tries free demo or Try Gate
  3. Human pays
  4. Human returns to Access

If step 1–4 hop across dead URLs, trust dies before compression ever matters.

Timeline

  • 2026-08-04 Canonical site declared: https://www.slidphilabs.com README and docs point at www as the under-construction-then-live commercial home — not a Vercel vanity hostname as brand.
  • 2026-08-04 Dead Try Gate / Access links replaced. Live Stripe checkout and GitHub paths where the temporary host was wrong. Buyers follow real money rails, not 404s.
  • Around this window (public surface work) www-only SEO practice. Canonicals, Open Graph URLs, sitemap, and discovery strings aligned to www so Google and agents don’t index a split brain of hosts.
  • Same product arc Suite and quote rails stay on www. /pps, quote APIs, and Access success returns belong on the brand domain so the process is one loop.

What we publish about “process” here

  • Where the lab lives (www only)
  • How you enter (home → web / try / suite)
  • How payment returns you (Access with session)
  • What agents fetch (discovery on the same origin)

We still don’t publish how the codec decides a byte. That’s not the process we’re selling in this post — we’re selling a trustworthy front door.

Takeaway

If you only bookmark one URL, make it www.slidphilabs.com. Everything else is a room inside the house.
