Try Gate Access loop: pay → verify → instant seat

Published 2026-08-07 · Same day as dual-surface platform ships

We said the next move was one closed money loop. Here it is: $9 Try Gate now unlocks a real evaluation seat on Access the moment Stripe says paid.

IP Guard: The seat unlocks public process — demos, guides, entitlement record. It does not dump private engines or secret sauce.

The loop (process)

  1. Buyer opens /try and chips in $9 (Stripe).
  2. Success lands on /access?product=try-gate&session=cs_… (configure Payment Link success URL — see host note).
  3. GET /api/access-verify reads the Checkout Session.
  4. If paid → instant deliverable: seat id, entitlement JSON download, eval guide, checklist, step links to web/standings/suite.
  5. If full product SKU (CDDG, ZRW tiers) → paid confirmed + structured PACKAGE ACCESS email path for private install.

What “instant” means

  • Entitlement JSON you can save (seat id, session, unlocks list)
  • Evaluation guide
  • Checklist
  • Public tools: /web, /standings, /truth, /pps

What it does not mean: open-sourcing the vault. Licensed packages remain a separate buy + fulfillment step.

Why this is the process story

Trust dies when “Access” means “email us forever.” Trust grows when payment maps to something you can hold in under a minute — even if that something is an evaluation seat rather than the private core.
