Hosted compression is dual-licensed. npm clients call the live host.

AWARE is hosted lossless compression. You send a file. We run every pathway we own. You get the smallest copy that still restores every byte. Dual-licensed: open terms, or a paid grant to ship closed. That is the product, and it is live.

Four npm packages now call that host. They are clients. They are not stubs.

  • slid-phi 2.3.0 — compress() / decompress()
  • spl-pay-per-suite 1.2.0 — quotes, checkout, MCP, same compress path
  • blackjack-compression 1.6.0 — same hosted path
  • @cptasz13/tru8 0.2.0 — zeros pack locally to 8 bytes; everything else uses hosted AWARE

A .pcc file is our zip: many files, one container, this compressor inside. zip() / unzip() on npm. POST /api/archive on the host.
