What it is

A compression service. Lossless: the file that comes back is the file you sent. Hosted: our machines run the pathways. You store, ship, and archive the small copy. Restore later with POST /api/decompress.

Zeros collapse to 8 bytes on the specialist door. Everyday files take every pathway we own; the smallest restore-safe result wins. A folder can become a .pcc container — many files, one archive, this compressor inside.

PCC Pro is $49/month and includes 200 GB. Then 8¢/GB. Usage is first 2 GB each month free, then 8¢/GB. TRUSTREAM (live logs) rides the same plan. Official 12-file corpus: /silesia.
