Same program. Same output. Or refuse.

CuNi is a 53-entry language catalog with one rule: a program prints the same stdout on every seat, or CuNi refuses to bless it. Fixed-point decimals, int64 time, onchain emitters — exactness you can check, not trust.

Porting bugs hide where languages disagree about numbers and time. CuNi makes the disagreement impossible to ship.

What it is / what it isn't

What it is: The exactness layer — a catalog, a checker, and a receipt. Rider seats use it when they want a same-stdout proof; auditors use it when they want one without trusting us.

What it isn't: Not a language, not a runtime, not a compressor. It checks programs; it doesn't run your infra.
