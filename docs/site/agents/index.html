Happy path

Agent buy flow

  1. Discover — GET /api/agent (or this page’s linked files).
  2. List SKUs — GET /api/x402-products.
  3. Request buy — POST /api/x402-products with { "sku": "suite free 1GB", "email": "ops@…" } → HTTP 402 + accepts[].
  4. Pay — exact USDC on Solana or Base; retry with X-PAYMENT.
  5. Receive — order_id + access_url (human Access page works too).
{
  "method": "POST",
  "url": "https://www.slidphilabs.com/api/x402-products",
  "body": { "sku": "cddg-split", "email": "agent-ops@example.com" },
  "then": "On 402, pay accepts[0], retry with X-PAYMENT"
}
