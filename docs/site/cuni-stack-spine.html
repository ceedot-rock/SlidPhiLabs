CuNi use case · The platform story

One substrate, six surfaces

The Slid Phi products read as six separate tools. They are one system, and CuNi is the reason it is one system instead of six: every boundary in the stack — language, chain, codec, ledger — answers to the same gate: byte-identical, or refuse.

Open Studio Back to CuNi

  • Agent-Rider (identity) runs on CuNi: an agent's policy must pass exactness before it is allowed to run — with the honesty note that Rider's require-PASS gate is off today. See Agent policy gate and /rider.
  • Warrant (spend mandates) is enforced by a CuNi law: spend-control.cuni (amount <= cap) is the meaning of the gate, proven identical on every seat. See /warrant and Money.
  • Chamber (two-key seal) seals JSON payloads; CuNi's canonical JSON is what makes "the same payload" a provable statement rather than a hope. A seal over non-canonical JSON is a seal over ambiguity.
  • PCC / pulsar (compression) are where the codec laws live: never-expand, arithmetic-coding roundtrips, tile laws — the primitives of the product, proven across targets. See Codecs and /pcc.
  • The x402 billing layer settles in integer cents against dec / time money types — the same types the fee and metering laws are written in. See Money.

That is the platform story: not six products, but one exactness guarantee with six surfaces. Each surface's use case is its own page, linked below, with its status stated honestly — proven, partial, or roadmap.

All CuNi use cases

  • FFI boundaries — Python, Rust, C, one behavior. Proven.
  • Consensus and blockchain execution — one escrow law, proven on EVM, Rust, and Go. Proven (logic cores).
  • Codecs: bit-exact decode — never-expand and arithmetic-coding roundtrips. Proven (primitives).
  • Money: settlement and Warrant budget trees — spend-control, rider-fee, suite-meter laws. In production use; chain accounting and x402 reconciliation are roadmap.
  • Deterministic builds and reproducible computation — receipts anyone can re-run. Partial.
  • CuNi as the audit source — foreign implementations proven against a gold law, signed receipts filed. Lab operating model.
  • Agent policy gate — an agent's policy, proven before it runs. Designed gate; Rider enforcement off today.
