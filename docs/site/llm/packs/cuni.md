# CuNi — LLM prompt pack (beta)

Compliance checks over your build. First 100 checks/month free, then $0.05
per check via x402. Studio use $0. Closed-app embedding needs the
[cuni_exception pack](cuni_exception.md) grant ($490/app/year).

An LLM running checks: batch inputs to stay inside the free 100, report
pass/fail per check with the receipt id, and stop batching up paid checks
without asking once the free quota is spent. Never cache a pass across
material input changes — re-check.
Status beta: pricing verified, served check endpoint not yet verified by us.
