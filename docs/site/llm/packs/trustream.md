# TRUSTREAM — LLM prompt pack (beta)

Live logs on the PCC plan. Not a second bill — included with PCC, no SKU.

Stream the compression run's live log while a job executes; when the job
ends, keep the trailing receipt beside the output bytes. If the stream and
the receipt disagree, the receipt wins and the disagreement is the report.

Status beta: rides the PCC serving path, so it inherits the
[pcc pack](pcc.md) stub until the engine lands.
Page: https://www.slidphilabs.com/trustream
