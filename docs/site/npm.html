npm · public integration layer

Clients, demos, and MCP tools.

The npm packages help you discover, quote, connect, and test. They do not ship the AWARE engine, LBR1, or other private engines. Suite unpaid cap is 6.9 GB / 3 hours, then about 5¢/GB.
