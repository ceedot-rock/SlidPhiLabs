What it is

CuNi is the exactness tool. You write one .cuni program. CLI v0.10.0 holds 53 targets. The gate that must match is Python, Go, and JavaScript. If those three would print different stdout, CuNi refuses the path and publishes the refusal. Studio is free. Bank takes a paste of N and emits X.

The CLI default cuni check runs the money seats: Python, Rust, Go, Java, SQL, and JavaScript. cuni check --all runs the 53-target catalog. A native seat that would diverge refuses. Solidity refuses a float, a list, or a type outside its model. Install the prebuilt binary with Homebrew. Protocol 1.1.1. Tag v0.10.0.

How it works

  1. Write the .cuni source once.
  2. Run the Python, Go, and JavaScript gate when you want those three to match.
  3. Run cuni check --all when you want all 53 targets.
  4. Use Bank when you want another catalog id from the same source, then prove it.

POST /api/pass on Studio returns pass or refuse for the three-language gate. The receipt is the answer you keep next to the job. cuni check --json --sign adds an Ed25519 signature a stranger can verify.

What you receive

You receive either identical stdout on the seats you asked for, or a refusal that names why the path stopped. You receive a free Studio, a Bank, and a protocol document. A closed-app grant for one product is a separate license.

Price

CuNi and Studio are free. The closed-app grant is $490 a year for one app under the unified grant: $490 a year for one product, $190 for the first 10 grants, $390 each for 3 or more products. Written, human-fulfilled, one product and one year, renewal at the then-current price. Per-check API: the first 100 checks a month are free, then $0.05 per check, with a customer-set monthly cap and an alert at 80% of the cap. The open license is AGPL-3.0-or-later.

Works with

Put the receipt beside a Rider job when you want proof the program matched. ExactOdds is the same rule on five seats and a pair of dice. Toll 5 on Tollkeeper is the listed price of selling that check.
