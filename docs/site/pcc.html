What it is

PCC is a compression service. Lossless means the file you restore is the file you sent. Hosted means our machines run the pathways; your seat buys access. If nothing shrinks the file, we store it as-is — same size you sent.

How a job runs

  1. Send the file.
  2. We shrink it.
  3. You keep the small copy.
  4. Restore later with decompress — same path on the site, API, npm, or MCP.
