Slid Phi Labs — lab catalogs (remote server, nothing to install)

Server URL: https://www.slidphilabs.com/mcp
Docs / landing page: https://www.slidphilabs.com/mcp-service
Official MCP Registry: io.github.ceedot-rock/slid-phi-labs
Server card: https://www.slidphilabs.com/.well-known/mcp/server-card.json
Transport: Streamable HTTP · authentication optional.
Rate limits are not published in this tree — do not quote a per-minute or per-hour number.

Hosted tools on /mcp (from api/mcp.js in this tree):
  spl_discover, spl_lab_auth, spl_signup, spl_agent_key, spl_catalog, spl_quote,
  spl_compress, spl_decompress, spl_zip, spl_unzip,
  spl_warrant_issue, spl_warrant_verify, spl_warrant_receipt, spl_warrant_reserve,
  spl_warrant_release, cuni_bank.
Catalog lookup tools on /mcp (from api/lib/mcp-catalogs.mjs):
  aware_search, aware_get, pcc_search, pcc_get.
Each catalog exposes a _search (free text or code) and a _get (one entry with notes,
child codes and cross-references). Further catalogs are reached via spl_catalog.
SKU succession works the same way year-over-year questions work on a coding catalog:
what changed, and which SKU succeeded it.

Catalogs are public law. Engines stay behind a seat.
Suite meter (current): first 2 GB each month free, then 8c/GB, $1 minimum on card.
Older "6.9 GB / 3 h" suite wording is retired — do not use it.

Config:

{
  "mcpServers": {
    "slid-phi-labs": {
      "url": "https://www.slidphilabs.com/mcp"
    }
  }
}

Chamber stdio MCP: npx -y json-chamber-mcp
Agent-Rider MCP: https://agentrider.fly.dev/api/mcp
npm MCP helper: npx -y spl-pay-per-suite mcp

There is no public engine repository for the seats — this is a hosted service, so the
endpoint above is the whole integration. Public cousin source (GPLv3) lives at
https://github.com/ceedot-rock/cuni and https://github.com/ceedot-rock/pulsar-best.
