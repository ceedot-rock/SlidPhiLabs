What it is

A streaming compressor. Grain is 4 KiB. Pipeline on each tile: ZERO → MATH → PHRASE → STORE. Quiet tiles pack small. Busy tiles keep their size so the stream never inflates. Restore is the original bytes in order.

It rides the PCC meter: first 2 GB/month free, then 8¢/GB, or PCC Pro at $49/month with 200 GB included.
