What it is

A hosted identity service for AI agents. Register. Issue a signed rider credential. Attach it to MCP and HTTP. Humans buy a team seat on Stripe. Agents can buy on x402. Official remote: https://agentrider.fly.dev/api/mcp.

Rider Ops ($29/mo · $290/yr) is heartbeat plus an alert when a signed agent goes quiet. Pair with Warrant for the mandate and the receipt.

What it is not (yet)

File transfer is not live — we will not market what is not shipped. A signed Rider is a credential peers verify via JWKS; it is not KYC-style “every agent is verified,” and it is not a compression crown. PCC is a different product.

Market

Agents already spend money, hit APIs, and ship code. The missing piece is a portable name. Rider sells that name. Warrant sells what the name is allowed to do.
