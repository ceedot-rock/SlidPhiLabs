What it is

A hosted identity service. Register. Issue a rider token. Attach it to MCP and HTTP. CuNi Studio can register a program after exactness passes. Humans buy a team seat on Stripe. Agents can buy on x402. Official remote: https://agentrider.fly.dev/api/mcp.

Rider Ops ($29/mo · $290/yr) is heartbeat plus an alert when a signed agent goes quiet. Pair with Warrant for the mandate and the receipt.

Future use

  • Fleets where every tool call is attributed to a named agent, not “the bot.”
  • Insurance and audit: a signed trail of who spent which dollar.
  • Marketplaces that only list agents with a live Rider and a trust score.
  • Studio publish: a program goes live only with a rider and an exactness pass.
  • Cross-company agents that present one identity at every gate.

Market

Agents already spend money, hit APIs, and ship code. The missing piece is a portable name. Whoever issues that name becomes the identity layer the same way Stripe became the card layer. Rider sells that name. Warrant sells what the name is allowed to do.
