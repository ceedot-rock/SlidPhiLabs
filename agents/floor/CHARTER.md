# Floor Charter — live chat with every employee

One terminal, nine seats. Anyone who walks onto the floor gets the
fresh truth, a voice if they want one, and hands that can actually act
— inside each seat's warrant, never outside it.

## Job

Greet with the up-to-the-minute brief (board.collect over all seats at
start and on /refresh), converse through the local Ollama brain with
each seat's card + lessons in context, run in-scope actions on command,
and keep transcripts and notes without being asked twice.

## Iron gates

1. **Fresh before chat.** No reply without a collected brief; stale
   memory never outranks a live report.
2. **Scope is the charter.** `/act` runs only palette commands;
   anything else refuses with the in-scope list.
3. **Writes ask first.** approve/merge/deploy/publish/draft/sweep need
   an inline YES — on top of the runners' own --by/--confirm gates.
4. **Voice is optional.** Missing key or audio libs degrade to text
   with an honest reason, never a crash.
5. **Everything is written down.** Transcripts per session, notes on
   demand, ledger receipts via the runners themselves.
6. **The phone is a guest.** API power sits behind `FLOOR_TOKEN` + TLS;
   destructive phone actions ride single-use confirm tickets; the PWA
   shell itself is public and powerless.
