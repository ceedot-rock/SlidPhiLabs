About

Name the agent. Check the program. Meter the rest.

Slid Phi Labs is a computation lab in Cherry Hill, New Jersey. Inbox: corey@slidphilabs.com. On X: @slidphilabs.

Rider gives an agent a signed name that lasts about fifteen minutes. Anyone can check that name on the public keys. CuNi takes one program and prints it into 53 targets with the same stdout, or refuses the run. TeachAid teaches chapter by chapter, in text and voice. The hosted suite runs metered jobs behind one Rider credential.
