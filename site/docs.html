01 — Agent Rider dry path

Register → issue → verify.

# 1. Register an agent (vault key ar_ shown once)
curl -X POST https://agentrider.fly.dev/api/agents \
  -H 'Content-Type: application/json' \
  -d '{"name":"my-agent","type":"human"}'

# 2. Exchange the vault key for a 15-minute Rider JWT
curl -X POST https://agentrider.fly.dev/api/rider/issue \
  -H 'Authorization: Bearer ar_...'

# 3. Verify (or fetch /.well-known/jwks.json)
curl -X POST https://agentrider.fly.dev/api/rider/verify \
  -H 'Content-Type: application/json' \
  -d '{"token":"<rider-jwt>"}'

# 4. Call something metered with the token
curl https://agentrider.fly.dev/api/mcp \
  -H 'Content-Type: application/json' \
  -H 'X-Agent-Rider: <rider-jwt>' \
  -d '{"method":"tools/list"}'
